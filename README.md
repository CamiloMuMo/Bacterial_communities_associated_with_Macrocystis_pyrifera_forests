# Variability of the bacterial communities associated with the giant kelp (Macrocystis pyrifera) and the adjacent sediments along the Strait of Magellan.
R scripts for the analysis of the bacterial communities associated with the giant alga Macrocystis pyrifera (project 1) and sediments (project 2) in the Magellan Strait, Chile. In addition to the environmental table containing each sample’s identifier, sampling site, sample type, and collection date, for project 1 and 2, all other metadata was generated using the DADA2 workflow and the R codes.
